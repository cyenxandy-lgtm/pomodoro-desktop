A lightweight Windows Pomodoro timer built with Tauri + React + Rust.

Rust-side reliable timer, SQLite statistics, system tray, global shortcuts, compact mode and themes.

Windows download available on [GitHub Releases](https://github.com/cyenxandy-lgtm/pomodoro-desktop/releases).

## Developer Version

Pomodoro Desktop is a Windows-first desktop Pomodoro timer built with Tauri 2, React, TypeScript and Rust.

- Rust `TimerManager` maintains authoritative timer state.
- Tauri provides desktop integration such as system tray, notifications, global shortcuts and window behavior.
- SQLite persists sessions and powers local statistics.
- Target-end-time reconciliation and persisted state support recovery after restart, background throttling and system sleep.

## User Version

- Windows desktop app
- Focus / Short Break / Long Break cycles
- Today / 7 Days / 30 Days statistics
- System tray and global shortcuts
- Compact Mode and Always On Top
- Dark / Light / System themes
- Local-first storage with no account or server required
